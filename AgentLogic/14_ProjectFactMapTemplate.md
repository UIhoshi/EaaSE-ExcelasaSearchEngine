# Project Fact Map Template

本文件是项目事实地图标准模板。

用途：

- 当 Agent 重新进入一个项目时，用它快速建立“项目事实层”。
- 它不替代主逻辑文件。
- 它用于承接主逻辑接入之后，对项目自身事实的结构化记录。

使用规则：

- 先完成主逻辑接入，再填写本模板。
- 先确认逻辑入口与目录边界，再填写项目事实。
- 若事实未确认，应明确标记为“未确认”，不要用猜测补齐。
