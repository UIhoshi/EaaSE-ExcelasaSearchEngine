# Future Enhancements

## 1. 目的

本文件用于记录那些已经被识别出有价值、但还不应直接进入主逻辑强制层的增强项。

## 2. 文件智能增强候选：Magika

参考项目：

- https://github.com/google/magika

### 当前判断

- 价值：有
- 是否可增强当前系统：可以
- 是否属于当前 V6 必需项：不是
- 当前建议状态：`candidate`

### 适合增强的点

- 无扩展名文件识别
- 扩展名伪装文件识别
- 更细粒度的文本类文件预分类
- 批量目录扫描时的预路由

### 为什么现在不是必需项

当前仓库已经具备基础文件分流能力，尤其在这些方向已有明确处理：

- 文本文件
- 图片
- PDF
- Notebook
- 二进制扩展名过滤

因此，`Magika` 更适合作为增强层，而不是当前主链路成立所依赖的前提。

### 后续何时可以升级

只有当满足以下条件时，才考虑把它从 `candidate` 提升：

1. 仓库内形成正式集成
2. 接入位置明确
3. 与 FileReadTool 或文件预路由层形成稳定调用关系
4. 权限、安全、性能影响已评估
